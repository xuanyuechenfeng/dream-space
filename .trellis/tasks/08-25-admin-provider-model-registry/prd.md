# 供应商与模型注册表

## Goal

建立供应商、模型、能力、凭据引用和健康探测的运营注册表。

## Requirements

- 管理供应商连接、模型能力和生命周期。
- 数据库仅保存外部 Secret 引用，任何接口和审计不处理密钥明文。
- 支持异步连接探测、标准化错误和健康快照。
- 保留现有 YAML 测试配置并作为 bootstrap 输入。
- 依赖 RBAC 子任务。

## Acceptance Criteria

- [ ] 供应商、模型和凭据引用 API/页面完整。
- [ ] 模型能力通过 Schema 验证。
- [ ] 密钥不出现在数据库业务字段、响应、日志和审计中。
- [ ] 健康探测有超时、限流和明确状态。
