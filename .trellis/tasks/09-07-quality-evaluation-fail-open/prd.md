# 质量评估超时配置与异常降级

## Goal

让图片质量评估调用使用统一的 `spring.ai.openai.timeout` 配置，并在评估服务异常时放行已经生成的候选图片，避免因评估链路故障误报图片生成失败。

## Requirements

- 质量评估请求不得继续使用固定的 90 秒超时，必须读取 Spring AI OpenAI 连接配置中的 timeout。
- 质量评估抛出运行时异常时，当前候选图片应跳过质量门禁并继续输出内容审核、持久化和结算。
- 质量评估异常不得调用槽位失败结算，也不得触发图片重新生成。
- 质量评估正常返回时，现有评分、拒绝和 refinement 循环行为保持不变。
- 图片内容审核、对象存储、数据库和额度结算异常仍按原逻辑失败。
- 保留结构化降级日志和 `task.slot.quality_skipped` 事件，不输出图片内容或敏感凭据。

## Acceptance Criteria

- [x] 质量评估 Prompt 的 timeout 等于 `spring.ai.openai.timeout` 绑定值。
- [x] 质量评估超时、网络异常、非法响应等运行时异常不会导致槽位失败。
- [x] 质量评估异常后，候选图片仍经过输出审核、持久化、发布和正常成功结算。
- [x] 正常质量拒绝、输出审核拒绝和持久化失败的既有测试行为不变。
- [x] Worker 质量评估相关单元测试通过。
