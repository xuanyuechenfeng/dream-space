# 用户详情与统一审计

## Goal

补齐用户详情运营工作台并统一管理操作审计查询。

## Requirements

- 实现用户概览、任务、额度流水、订单、会话和操作记录六个标签页。
- 新增统一追加写 `AuditEvent`，支持跨 Billing/Moderation 查询。
- 详情查看、导出和写操作均按权限审计并脱敏。
- 依赖 RBAC 子任务。

## Acceptance Criteria

- [ ] 用户聚合数据归属正确且可分页下钻。
- [ ] 审计支持时间、操作者、动作、资源、结果和请求 ID 筛选。
- [ ] 敏感字段不进入响应、日志或审计快照。
- [ ] 用户启停和会话撤销在详情页可完成并留下审计。
