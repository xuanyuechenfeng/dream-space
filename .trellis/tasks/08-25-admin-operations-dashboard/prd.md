# 运营数据看板

## Goal

提供面向运营人员的用户、生成、财务、模型可靠性和风险总览。

## Requirements

- 区分业务聚合、财务事实和运行时监控三类数据源。
- 展示 KPI、趋势、模型健康、业务漏斗、风险告警和高风险操作。
- 每个指标返回数据时间和聚合状态，支持下钻到专业页面。
- 依赖用户详情、统一审计、日聚合和财务报表子任务。

## Acceptance Criteria

- [ ] 看板指标与源报表口径一致。
- [ ] 数据延迟和失败不会显示为零值。
- [ ] 权限过滤和服务端鉴权一致。
- [ ] 1440x900、800x1024、390x844 视觉、文本和键盘操作通过。
