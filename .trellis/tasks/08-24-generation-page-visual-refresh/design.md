# 技术设计

## 视觉方向

采用“浅灰画布 + 白色工作台”的精致生产工具风格，参考即梦的空间分层：主导航使用很浅的灰底，生成页会话栏保持白色，中央工作区使用低对比度画布，主输入框以白色浮层突出。强调色采用青绿色，避免覆盖现有业务语义。

## 实现边界

- 在 `src/styles.css` 覆盖生成页相关选择器，尽量复用既有 class，减少模板变更。
- 仅在生成页模板增加语义性的 aria/title 或视觉钩子时才修改 `GenerationWorkspaceView.vue`。
- 不改变 `generation` store 及其调用链。

## 验证

- 使用 Vite 本地开发服务器加载 `/generate`（未登录时允许检查登录跳转，必要时检查静态构建）。
- 通过 Playwright 截图检查桌面 1440px 和移动 390px 视口，确认无溢出与遮挡。
