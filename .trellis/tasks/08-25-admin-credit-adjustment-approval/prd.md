# 额度调整审批

## Goal

实现可审计、幂等、支持双人复核的额度赠送和扣减流程。

## Requirements

- 新增 `CreditAdjustment` 调整单和申请、批准、拒绝、取消、执行状态机。
- 小额赠送可按配置自动批准，大额赠送和所有扣减需要第二人复核。
- 扣减只使用 available，不得占用 reserved 或产生负余额。
- 最终变更必须通过额度事务服务写不可变流水。
- 依赖 RBAC 和统一审计子任务。

## Acceptance Criteria

- [ ] 幂等重试只产生一张调整单和一条额度流水。
- [ ] 申请人不能复核自己的请求。
- [ ] 并发扣减不破坏额度恒等式。
- [ ] 失败、拒绝和执行结果均可查询并审计。
