# 管理端运营能力后续实施计划

本任务只交付设计。后续实现建议拆成可独立验收的子任务，按以下顺序推进。

## Phase 1：补齐现有管理能力

- [ ] 新增用户详情路由和资料、任务、订单、额度、会话、审计标签页。
- [ ] 新增管理员账号列表、启停和会话撤销。
- [ ] 建立 RBAC 表、权限码注解、权限缓存与鉴权契约测试。
- [ ] 补齐计费规则编辑、预览、冲突检测、发布和回滚页面。
- [ ] 建立 `CreditAdjustment` 申请、复核、执行和拒绝流程。
- [ ] 建立统一审计事件和跨领域查询接口。

## Phase 2：模型运营

- [ ] 建立供应商、模型、密钥引用和健康探测。
- [ ] 建立版本化路由、目标权重、能力匹配和发布回滚。
- [ ] Worker 接入路由快照、重试、熔断、降级和调用事实记录。
- [ ] 生成任务保存路由、供应商、模型和计费规则快照。

## Phase 3：财务与配置

- [ ] 建立账单、收入、退款、点数、模型成本和毛利日聚合。
- [ ] 建立报表查询、导出任务和数据口径校验。
- [ ] 建立系统配置定义、版本、发布、回滚和节点生效回执。

## Phase 4：运营看板

- [ ] 建立用户、生成、收入、额度和模型可靠性指标卡。
- [ ] 建立告警、异常趋势和高风险操作流。
- [ ] 完成桌面、平板、移动端视觉与可访问性回归。

## 每阶段验证

- [ ] 数据迁移在空库和存量库均可执行，回填可重入。
- [ ] API 契约、事务、并发、幂等和越权测试通过。
- [ ] 管理端 typecheck、构建、组件测试和关键 E2E 通过。
- [ ] PostgreSQL、Redis、Worker 和供应商异常注入符合降级设计。
- [ ] 发布前完成旧新口径对账，回滚不破坏历史快照。
