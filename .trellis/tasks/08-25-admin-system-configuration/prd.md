# 系统配置中心

## Goal

建立安全、版本化、可预览和可回滚的在线业务与运行策略配置中心。

## Requirements

- 配置定义包含类型、Schema、默认值、环境、负责人和动态性。
- 发布完整不可变快照，服务实例校验并上报应用回执。
- 不纳管数据库、Redis、对象存储地址和任何密钥明文。
- 回滚通过发布历史值的新版本实现。
- 依赖 RBAC 子任务。

## Acceptance Criteria

- [ ] 类型、Schema、跨字段和环境约束验证完整。
- [ ] 非动态配置不会在运行中部分生效。
- [ ] checksum 错误时实例保留上一快照并上报失败。
- [ ] 发布、回滚和实例回执均可审计查询。
