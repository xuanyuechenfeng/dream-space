# 管理员账号与角色管理

## Goal

提供管理员账号、角色和权限配置的完整管理端能力。

## Requirements

- 实现管理员列表、创建/邀请、启停、角色分配和会话撤销。
- 实现系统/自定义角色列表、编辑和权限矩阵。
- 禁止自我禁用、移除自己的唯一管理角色和禁用最后一个 ADMIN。
- 所有写操作要求原因、乐观锁和审计。
- 依赖 `08-25-admin-rbac-authorization`。

## Acceptance Criteria

- [ ] 管理员与角色 API、页面和权限校验完整。
- [ ] 角色并发编辑返回明确冲突。
- [ ] 高风险保护规则和会话失效生效。
- [ ] 桌面、平板、移动端和键盘操作验收通过。
