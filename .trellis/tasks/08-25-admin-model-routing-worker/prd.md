# 模型路由与 Worker 接入

## Goal

实现版本化模型路由、灰度选择、重试、熔断和降级，并接入 Worker。

## Requirements

- 建立 route/version/target 数据模型和草稿发布回滚流程。
- 按 stage、请求能力和灰度上下文选择目标，同优先级稳定哈希加权。
- 区分可重试错误、可降级错误和业务终态。
- Worker 保存路由、供应商、模型和调用尝试事实。
- 依赖供应商与模型注册表。

## Acceptance Criteria

- [ ] 路由选择稳定、可解释且能力匹配。
- [ ] 429/5xx 可重试降级，审核拒绝不降级。
- [ ] 熔断和半开恢复符合阈值，Redis 故障有本地退化。
- [ ] 重试或降级不重复扣用户点数。
