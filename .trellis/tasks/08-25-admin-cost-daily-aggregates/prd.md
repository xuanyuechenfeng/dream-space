# 模型调用成本与日聚合

## Goal

建立用户、生成、额度、账单和模型成本的可重算日聚合数据层。

## Requirements

- 实现五类日聚合表和 `AggregateRun` 运行记录。
- D+0 增量并重算 D-2..D，支持延迟支付和退款。
- 聚合可重入、可校验、可下钻到原始事实。
- 依赖模型调用事实和现有 Billing 数据。

## Acceptance Criteria

- [ ] 同一窗口重复运行结果和 checksum 一致。
- [ ] 收入、退款、点数和调用成本口径与设计一致。
- [ ] 聚合失败不影响交易和生成主链路。
- [ ] 最近 90 天回填与明细对账通过。
