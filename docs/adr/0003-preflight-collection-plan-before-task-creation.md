# Preflight the image collection plan before creating a task

Resolve and validate the Image Collection Plan in a short-lived, non-billable Collection Preflight before creating a Generation Task or reserving credits. The API snapshots the pricing rule and queues the preflight; the Worker asynchronously performs moderation and model planning, then atomically publishes the frozen plan and its readiness event. A signed, single-use Plan Token binds the ready plan to normalized inputs for ten minutes; task creation consumes that token and execution reuses the frozen plan. This adds a two-step protocol behind one user action, but keeps model work out of the API, prevents ambiguous or over-limit requests from creating billable history, and makes the reserved amount a fact rather than a model guess.
